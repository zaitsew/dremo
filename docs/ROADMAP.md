# Dremo roadmap

## v0.1 (this build)

Clocks, six ambience scenes with synthesized sound, optional weather, sleep
timer, night dimming and pixel shift, and a screensaver service.

## v0.2

- Photo frame from a USB drive or a shared folder on the home network.
- More scenes: snow, forest, aquarium.
- Per-scene colour themes.

## v0.3

- A calendar line from a public iCal URL.
- A "morning" mode (clock, weather and agenda) that starts on a schedule.

## Later, only on a trigger

- A one-time "supporter" unlock through Play Billing. Never ads.
